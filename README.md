# TechDebt-Hub

> 🚧 **Projeto em desenvolvimento ativo.** Algumas funcionalidades ainda estão sendo implementadas.

Sistema de gestão de débitos técnicos, construído como projeto autoral para explorar e aplicar padrões arquiteturais de nível profissional em um cenário prático.

## Sobre o projeto

O TechDebt-Hub tem como objetivo demonstrar a aplicação de arquitetura limpa e padrões modernos de desenvolvimento back-end, incluindo:

- **Clean Architecture** — separação clara de responsabilidades entre camadas
- **CQRS** com **Vertical Slice Architecture** — organização por funcionalidade, não por camada técnica
- **Domínio rico** — entidades com máquina de estados controlando transições válidas
- **Motor de priorização** — cálculo automático de prioridade dos débitos técnicos cadastrados

## Tecnologias
